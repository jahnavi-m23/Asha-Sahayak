# ASHA SAHAYAK (ಆಶಾ ಸಹಾಯಕ)
> **AI-Powered Voice-Based Field Register for ASHA Workers**

---

## 📌 Phase 2 Overview: AI Understanding, Data Extraction and Safety

Phase 2 acts as the cognitive, safety, and conversational intelligence engine of **ASHA SAHAYAK**. It receives multilingual voice transcripts generated by Phase 1, extracts structured maternal and child health fields using **Qwen AI**, checks predefined clinical danger signs based on official **MoHFW** and **WHO/IMNCI** public health protocols, conducts voice read-backs using **Gnani Timbre v3.0**, and facilitates iterative voice corrections before handing confirmed records to Phase 3.

## 🚀 Setup Instructions

### 1. Prerequisites
- Python 3.10+ (Tested on Python 3.14)
- Virtual Environment (`venv`)

### 2. Virtual Environment Setup
```bash
# Create virtual environment
python -m venv .venv

# Activate virtual environment (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 3. Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Key variables configured in `.env`:
- `QWEN_API_KEY`: API Key for Qwen LLM (DashScope or OpenAI-compatible endpoint).
- `QWEN_API_BASE`: Base URL (default: `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`).
- `QWEN_MODEL_NAME`: Model name (default: `qwen-plus`).
- `GNANI_API_KEY` / `GNANI_TOKEN`: Credentials for Gnani Timbre v3.0 TTS.
- `GNANI_TIMBRE_URL`: Endpoint (default: `https://api.gnani.ai/timbre/v3/synthesize`).
- `PHASE_3_ENDPOINT_URL`: Shared backend endpoint (default: `http://localhost:8000/api/records/save`).
- `ALLOW_MOCK_FALLBACK`: `true` enables deterministic heuristic extraction and synthetic audio for offline testing.

### 4. Running the FastAPI Server
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
```
API Documentation will be accessible at: `http://localhost:8000/docs`

## 🔄 API Contracts & Integration Guide

### 1. Phase 1 Input -> Phase 2 Processing
**Endpoint**: `POST /api/ai/process-transcript`

**Request Payload**:
```json
{
  "transcript": "The baby weight is 3.2 kg and OPV-1 is due.",
  "language": "kn-en",
  "status": "completed",
  "beneficiary_id": "BNF-2041"
}
```

**Response Payload**:
```json
{
  "record": {
    "beneficiary_id": "BNF-2041",
    "visit_type": "Newborn home visit",
    "weight": "3.2 kg",
    "vaccinations_due": ["OPV-1"],
    "next_visit_date": null,
    "missing_fields": ["next_visit_date"],
    "danger_signs": [],
    "referral_required": false,
    "confirmation_status": "pending",
    "clarification_prompt": "Next visit date record aagilla. Yavaga next visit schedule madbeku?",
    "readback_text": "Baby weight is 3.2 kg. OPV-1 vaccination is due. Is this correct?"
  },
  "voice_readback": {
    "readback_text": "Baby weight is 3.2 kg. OPV-1 vaccination is due. Is this correct?",
    "language": "kn-IN",
    "audio_base64": "UklGRiQAAABXQVZFZm10IBAAAA...",
    "audio_format": "wav"
  }
}
```

### 2. Voice Correction Loop
**Endpoint**: `POST /api/ai/correct-record`

**Request Payload**:
```json
{
  "correction_transcript": "No, weight is 2.8 kilograms.",
  "language": "en",
  "current_record": {
    "beneficiary_id": "BNF-2041",
    "visit_type": "Newborn home visit",
    "weight": "3.2 kg",
    "vaccinations_due": ["OPV-1"],
    "next_visit_date": null,
    "missing_fields": ["next_visit_date"],
    "danger_signs": [],
    "referral_required": false,
    "confirmation_status": "pending"
  }
}
```
*Behavior*: Updates only the weight field (`2.8 kg`), preserves `beneficiary_id` and `vaccinations_due`, re-synthesizes readback, and maintains confirmation status as `in_review`.

### 3. Explicit Confirmation -> Phase 3 Handoff
**Endpoint**: `POST /api/ai/confirm-record`

**Request Payload**:
```json
{
  "confirmed": true,
  "record": { ... }
}
```

**Payload Sent to Phase 3** (`PHASE_3_ENDPOINT_URL`):
```json
{
  "beneficiary_id": "BNF-2041",
  "visit_type": "Newborn home visit",
  "weight": "3.2 kg",
  "vaccinations_due": ["OPV-1"],
  "next_visit_date": null,
  "danger_signs": [],
  "referral_required": false,
  "confirmation_status": "confirmed"
}
```

### 4. Real-Time Conversational Flow
**WebSocket Endpoint**: `ws://localhost:8000/api/ai/ws/interaction`
Supports bidirectional events:
- `process_transcript` -> `record_extracted`
- `correct` -> `record_corrected`
- `confirm` -> `record_confirmed` (with Phase 3 handoff result)

## 🛡️ Public Health Safety & Danger Signs Matrix

| Code | Danger Sign | Category | Guidelines Citation | Action / Referral |
|---|---|---|---|---|
| `HBNC-DS-01` | High fever in newborn (> 38°C) | Newborn | MoHFW HBNC Guidelines & WHO/UNICEF IMNCI | Urgent referral to PHC/CHC. Keep baby warm. |
| `HBNC-DS-02` | Hypothermia (< 35.5°C) | Newborn | MoHFW HBNC Module 3 | Provide Kangaroo Mother Care; emergency transport to PHC/FRU. |
| `HBNC-DS-03` | Inability to feed / suckle | Newborn | WHO/UNICEF IMNCI Protocols | Critical danger sign; emergency transport to PHC/FRU. |
| `HBNC-DS-04` | Convulsions / Fits / Tremors | Newborn | MoHFW HBNC Manual & IMNCI | Critical emergency; clear airway, rush to FRU/District Hospital. |
| `HBNC-DS-05` | Fast breathing / Chest indrawing | Newborn | MoHFW HBNC Respiratory Distress Protocols | Urgent referral to PHC/CHC equipped with oxygen support. |
| `HBNC-DS-06` | Severe Jaundice (Day 1 / Palms / Soles) | Newborn | MoHFW HBNC Neonatal Jaundice Protocol | Refer to PHC for phototherapy and bilirubin evaluation. |
| `HBNC-DS-07` | Umbilical sepsis / Pus discharge | Newborn | MoHFW HBNC Umbilical Sepsis Guidelines | High priority; keep dry, do not apply home remedies, refer to PHC. |
| `ANC-DS-01` | Vaginal bleeding in pregnancy (APH) | Pregnancy | MoHFW Antenatal Care (ANC) Guidelines | Critical emergency; arrange 108 Ambulance immediately to FRU. |
| `ANC-DS-02` | Severe headache + blurred vision / High BP | Pregnancy | MoHFW ANC Guidelines: Pre-eclampsia | Critical emergency; refer immediately to FRU/CHC. |
| `ANC-DS-03` | Eclampsia / Convulsions in pregnancy | Pregnancy | MoHFW Emergency Obstetric Care (EmOC) | Left lateral position, clear airway, rush to FRU via 108 Ambulance. |
| `PNC-DS-01` | Postpartum Hemorrhage (PPH) | Postpartum | MoHFW Postnatal Care & PPH Management | Critical emergency; urgent transport to FRU. |
| `PNC-DS-02` | Foul-smelling lochia / Puerperal sepsis | Postpartum | MoHFW Postnatal Care Manual | Urgent evaluation at PHC for puerperal sepsis. |

### Strict Public Health Rules Enforced
1. **Zero Hallucination**: Never invent missing beneficiary IDs, dates, weights, or vaccines. Missing items are set to `null` and listed in `missing_fields`.
2. **No Medical Prescription**: Never prescribe medications, suggest drugs (e.g., paracetamol, antibiotics), or specify dosages.
3. **No Clinical Diagnosis**: Never declare clinical disease diagnoses; prompt immediate transfer to authorized public health centers (PHC, CHC, FRU).
4. **Context & Negation Checking**: Statements like "no fever", "ಜ್ವರ ಇಲ್ಲ", "bleeding illa", or conditional advice ("if fever occurs...") do not trigger false positive emergency alerts.
